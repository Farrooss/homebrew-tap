# Farrooss Homebrew tap

Homebrew formulae for [Farrooss](https://github.com/Farrooss)'s projects. Works on macOS and Linux.

```sh
brew install farrooss/tap/hackterm
```

| Formula | Description |
|---|---|
| [hackterm](https://github.com/Farrooss/hackterm) | A cinematic fake-hacking console for your terminal |
